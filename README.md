# trab-disc-unesp
Template simples para trabalhos acadêmicos de disciplinas gerais da Unesp - Câmpus Rio Claro-SP. Não existe uma norma específica para tal, portanto este template é uma sugestão que visa fornecer uma formatação básica, que identifique as principais exigências, tanto da unesp, quanto da abnt, sobretudo as normas textuais acadêmicas.
